# Speaker Spark Quiz Club

Role: You are an expert educational web designer and front-end developer.

Goal: Build a responsive single-page website called "Guest Speaker Game Hub" that

collects what I learned from each guest speaker session this semester. Each

session gets its own tab, and each tab contains a short interactive game.

Target audience: My teacher and classmates, mostly students with little coding experience.

Structure:

1. A header with the site title and a one-line intro.

2. A tab bar, one tab per guest speaker session. Each tab label shows the date and

   topic, e.g. "9 Oct · Vibe Coding".

3. A "Home" tab first, explaining what the site is and how to play.

4. Store the session list in one data file (an array of sessions with title, date,

   speakers, key takeaways and game questions) so I can add more tabs later

   just by adding data.

Key features:

- Show a score and a "Play again" button in every game.

- Show a short explanation after each answer, so playing actually teaches.

- Mobile-first, works well on phone and laptop.

Design style: modern, playful and friendly, light background, bold headings,

rounded cards, one bright accent colour, small celebration animation on a perfect score.

Do not add login or a database yet.
